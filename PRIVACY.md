# Privacy Policy

Last updated: October 16, 2026

Ibintec After Effects MCP runs on your own computer. Ibintec Limited does not
operate a hosted service for it and does not receive your projects, files,
requests, or results.

## Local data

The MCP server and the Ibintec AE Bridge panel exchange a command file and a
result file in the bridge folder (`<user profile>\ibintec-ae-bridge` on
Windows, `~/ibintec-ae-bridge` on macOS). These files can contain composition
and layer names, text you add to compositions, and command results.
`view-comp` briefly stores rendered frames in that folder and deletes them
after use.

## Images and results sent to your AI client

Tool results, including the frames returned by `view-comp`, go to the AI
client that called the tool so it can work with them. If that client is a
cloud service (for example Claude), they are sent to that service and handled
under its privacy policy, like anything else you share with it.

## Third parties

Downloading from GitHub, installing dependencies through npm, using Adobe After
Effects or ffmpeg, and using an MCP client such as Claude Desktop are governed
by those providers' own terms and privacy policies.

## No analytics

The software contains no analytics or telemetry and sends nothing to Ibintec
Limited.
